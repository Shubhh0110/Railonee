# RailOne Mobile-Friendly Web Portal

A high-performance, mobile-first railway booking and live tracking web application inspired by the official **RailOne Indian Railways Super App**.

## Features Included
- **Mobile-First Design**: App-like bottom navigation bar, touch-friendly buttons, card carousels, and responsive layouts.
- **Unified Services Hub**:
  - Reserved, UTS suburban, Tatkal, and Platform ticket options.
  - One-tap From/To station swap button.
  - PNR status checker with coach & berth visualizer.
  - Live Train Spotting & delay updates.
  - IRCTC E-Catering seat delivery integration.
- **Utilities**: R-Wallet, Rail Madad (139 helpline), Coach Position indicator, and Refund tracking.
- **Pure Native Stack**: Zero external JavaScript frameworks (Vanilla HTML5, CSS3, and modern ES6 JavaScript).

## How to Run
1. Unzip `railone-web-project.zip`.
2. Open `index.html` in any modern web browser or mobile browser.
3. You can deploy it directly to GitHub Pages, Netlify, Vercel, or Apache/Nginx web servers.
